# cryptorate
CryptoRate - приложение с графическим интерфейсом на языке Python, которое отображает текущие курсы популярных криптовалют, используя данные открытого API.
# Установка
Для установки необходимо установить python версии не ниже 3.8.
Установить требуемые библиотеки:
pip install -r requirements
# Запуск
python cryptorate.py
